# 药学院每周工作计划

手机端优先的工作计划填报与汇总系统。老师按姓名登录，在日历上点任意一天填写当天计划；管理员可查看全部记录、管理账号、导出汇报级 HTML 报告。

**正式地址：<https://pharmacy-week-plan.app.workbuddy.host/?sharecode=XKGUZCHHUF>**

> 本 GitHub 仓库现在只作为**代码存档 + 入口跳转页**。打开 <https://guan4425390.github.io/yaoxueyuan-weekly-plan/> 会自动跳到上面的正式地址。
> 原因：GitHub Pages 是纯静态托管，跑不了数据库；第二版改成了后台模式，必须用带数据库的宿主。数据全部落在云端 PostgreSQL，手机、电脑、平板看到的是同一份数据。

## 功能

| 功能 | 说明 |
| --- | --- |
| 登录 | 账号为教师姓名，初始密码 `666666`，首次登录建议自行修改 |
| 日历 | 覆盖未来五年，按月 / 按年翻页、回到今天；**每一格都可点击**新建计划 |
| 计划录入 | 时间、工作地点（预设下拉 + 自定义）、参与人员、工作事项、备注 |
| 日历标记 | 有计划的日期显示 ①②③ 简略序号，超出显示「+N」，点开看当日明细 |
| 条数上限 | 默认每天 10 条，根管理员可在后台调整 |
| 汇总导出 | 仅管理员可用；按时间分组 / 按人物分组；自定义起止日期或「本周」等快捷；写明星期几并用 ★ 标出管理员 |
| 导出格式 | 生成一份**独立美观的 HTML 报告**，可直接打开、打印或发邮件用于汇报 |
| 账号管理 | 根管理员可新增账号、改角色、重置密码、**解锁被锁账号**、修改或删除其他管理员 |
| 操作记录 | 根管理员可查看所有人「谁 / 什么时候 / 新增或修改了什么」 |
| 存储容量 | 设置页显示后台已用容量与剩余空间，并提供一键清空（仅清计划，账号保留） |

## 角色

| 角色 | 权限 |
| --- | --- |
| 根管理员 | 全部权限：导出、账号管理、解锁、操作记录、容量与清空 |
| 管理员 | 导出汇总表、查看全部计划 |
| 教师 / 辅导员 | 填报与查看本人及全院计划 |

连续输错密码会锁定账号，由根管理员在「设置 → 账号」里点「解锁」恢复。

## 后台结构（云端 PostgreSQL）

| 表 | 用途 |
| --- | --- |
| `plans` | 计划记录：`id / date / time / place / topic / people / note / author / is_demo / created_at / updated_at` |
| `accounts` | 账号：`name / role / pwd(SHA-256) / locked / created_at` |
| `op_logs` | 操作记录：`ts / actor / action / detail / target` |
| `app_settings` | 参数：`max_per_day`、常用地点、容量配额 |

- 密码不存明文，前端 `sha256(name + '|' + pwd)` 后再比对。
- 4 张表均启用 RLS，并授予 `authenticated, anon` 角色读写权限。
- `storage_bytes()` 为 `SECURITY DEFINER` 函数，用 `pg_total_relation_size` 汇总各表物理占用，供前端显示容量。
- 初始数据：21 个账号（5 名根管理员 + 16 名辅导员）、5 条标注「示例」的演示计划、默认参数。

## 本地构建

页面为单文件（校园水墨横幅已 base64 内嵌），源模板是 `app.template.html`：

```
python3 tools/build.py      # 生成 index.html 与 dist/index.html，并跑静态校验
node tools/live_test.mjs    # 线上端到端测试（需本机 Chrome 开 9222 调试端口）
```

`tools/github_entry.html` 是推送到 GitHub 的入口跳转页。
