# 药学院每周工作计划

一个手机端优先的工作计划填报与汇总工具。老师按姓名登录，在日历上选日期填写当天计划；管理员可按时间或按人物导出汇总表。

## 功能

| 功能 | 说明 |
| --- | --- |
| 登录 | 账号为教师姓名，初始密码 `666666`；登录后可自行改密码 |
| 日历 | 覆盖未来五年，支持按月 / 按年翻页、回到今天 |
| 计划录入 | 时间、工作地点（预设下拉 + 自定义）、参与人员、工作事项、备注 |
| 日历标记 | 有计划的日期显示 ① ② ③ 简略序号，超出显示「+N」，点开看当日明细 |
| 条数上限 | 默认每天 10 条，管理员可在设置里调整 |
| 汇总导出 | 仅管理员可用；按时间分组 / 按人物分组；自定义起止日期或「本周（周一起）」等快捷；表格写明星期几并用 ★ 标出管理员；可下载 Excel、CSV，或打印存 PDF |
| 账号管理 | 管理员可新增账号、切换管理员身份、重置密码、维护常用地点 |
| 数据备份 | 导出 / 导入 JSON 数据包，用于跨设备汇总 |

## 数据存放说明（重要）

本站点是纯静态页面，**默认把数据存在各自浏览器里**：

- 同一台手机、同一个浏览器里，不同账号之间能看到彼此填的计划；
- 换一台手机、换浏览器、清缓存后看不到原来填的内容；
- 计划内容不会上传到任何服务器。

如果需要**多台手机实时共享同一份数据**，由管理员在「设置 → 共享数据源」里填一个接口地址：

- `GET <接口地址>` 返回 `{"plans": [ ... ]}`（也接受直接返回数组）
- `PUT <接口地址>` 请求体 `{"plans": [ ... ]}`，用于写回全部数据
- 如接口需要鉴权，可填「访问密钥」，会以 `X-Api-Key` 请求头带上

启用后每次改动会自动推送，打开页面时会从云端拉取。没有接口时，用「导出数据包 / 导入数据包」也能把各台手机的数据合并汇总。

## 每日计划字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `date` | `YYYY-MM-DD` | 日期 |
| `time` | 文本 | 如 `08:30-10:00` |
| `place` | 文本 | 工作地点 |
| `topic` | 文本 | 工作事项 |
| `people` | 文本 | 参与人员 |
| `note` | 文本 | 备注 |
| `author` | 文本 | 填录人姓名（登录账号） |

## 本地构建

页面为单文件 `index.html`（校园风格图已内嵌）。如需重新生成：

```
python3 tools/build.py
python3 tools/selftest.py
```

`tools/selftest.py` 会生成一份带自测脚本的临时页面，用无头浏览器跑完 29 项功能校验。
